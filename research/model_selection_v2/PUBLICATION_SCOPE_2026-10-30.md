# Publication scope — 30 October 2026

This publication includes original code/tests, specifications, aggregate results,
bootstrap summaries, plots, frozen manifests, hashes and historical verification
reports. Scientific outputs were not changed or recomputed for publication.

New record-level prediction/loss arrays, bootstrap multiplicities/draw arrays,
selection/evaluation identity tables, transformation registries, fitting references,
input identity audits and prediction-reuse audits are excluded conservatively.
Bundled source snapshots are excluded; dependency names, versions and hashes remain
in freeze/run manifests. Obtain dependencies from the referenced upstream sources
and review their licenses before use. All excluded originals remain locally intact.
These exclusions apply to this new publication; existing Git history is preserved.

Verification limitation: VERIFIED.json and freeze receipts describe the complete
local runs. Their full artifact checks cannot pass from this partial publication
alone. Aggregate tables and reported intervals can be inspected, but record-level
reconstruction and complete hash verification require the excluded artifacts.
Missing snapshots also prevent full historical freeze verification until restored
with the exact recorded bytes. Do not interpret published receipts as verification
of a complete downloadable run.

Regeneration instructions and dependency contracts are in selection_exploration_v1/README.md,
judge_v1/README.md and the original run manifests. Use an authorized local copy of
the cited UCI data and frozen pilot inputs. Run documented commands only into fresh
destinations; never overwrite completed runs. Newly generated artifacts need not
be byte-identical to the historical receipts. No experiments were run for this task.
