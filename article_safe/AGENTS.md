`verify_stage(run_path / stage, protocol)` from `article_safe.artifacts`, using
the returned protocol for `selection`, `evaluation` and `report`. These check

`.venv/Scripts/python.exe -m unittest discover -s article_safe/tests -v`.

Future methods need a separately specified version. New article executions need
fresh run IDs and explicit research scope. Do not run preparation, selection,
evaluation, reporting or final verification for routine documentation work.
