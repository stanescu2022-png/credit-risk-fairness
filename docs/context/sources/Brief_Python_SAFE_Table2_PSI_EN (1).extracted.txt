5. Reproducing Table 2 — Fairness
For each variable, compare the Shapley values between gender groups (SEX == 1 vs. SEX == 2). Report F_k (Gini) and the p-value (Kolmogorov–Smirnov).
The formulas
Shapley (eq. 1): phi(f_hat(X_i)) =   SUM over X' subset of X\{X_k} of      [ |X'|!(K-|X'|-1)!/K! ] * [ f_hat(X'uX_k)_i - f_hat(X')_i ]v_.k = SUM_m v_mk ;  q_mk = v_mk / v_.kF_k  = Gini( q_masc,k , q_fem,k )D_k  = max_x | F_masc(x) - F_fem(x) | ;  p_k = probabilitatea KS

How to read it
p_k > 0,05 → fair on variable k (no significant difference between genders).
p_k < 0,05 → possible bias; F_k reports the magnitude of concentration.

6. Governance indicator: Population Stability Index (PSI)
6.1 What PSI measures, step by step
PSI measures how much the distribution of model scores drifts between two samples. Here we compare the TRAINING set (reference) with the TEST set. The idea, step by step:
The model produces a score (default probability) for every observation.
We split the score range into bins (usually 10 deciles), defined on the training scores.
We compare the proportion of scores in each bin, on training (E_i) versus test (A_i).
If the proportions are similar, the distribution is stable (low PSI); if they differ a lot, there is drift (high PSI).
6.2 PSI as a governance indicator
In bank model-risk management practice, PSI is the standard model-monitoring metric: a significant drift triggers model revalidation and human oversight. PSI therefore acts as a measurable proxy for the Governance dimension (monitoring, oversight, accountability), which the SAFE framework does not cover directly. In this way, PSI extends SAFE with a fifth, governance-oriented facet.
Honesty note (to include in the paper): governance is largely procedural; PSI measures one facet (stability/monitoring), not the whole of governance. State this explicitly as a proxy, not a complete measure of governance.
6.3 The statistical formula
PSI = SUM over bins i of ( A_i - E_i ) * ln( A_i / E_i )E_i = proportion of TRAINING (expected) scores in bin iA_i = proportion of TEST (actual) scores in bin iBins are defined from the TRAINING scores (10 deciles).Use the SAME bin edges for both distributions.
6.4 The process, step by step
Train each model (already done for SAFE).
Generate the score (default probability) for TRAINING and for TEST.
Define the bins from the training scores (10 deciles). Do NOT re-bin on test.
Compute the proportions E_i and A_i for each bin.
Apply the formula per bin and sum.
Read against the thresholds; report one PSI per model (and, optionally, PSI per bin).
Technical caution: a bin may have 0 observations in test, making ln(A_i/E_i) blow up; add a small floor (eps = 0.0001) to the proportions before the log.
6.5 Python code
import numpy as npdef population_stability_index(expected, actual, n_bins=10):    # bin edges from the reference (training) scores, by decile    q = np.linspace(0, 1, n_bins + 1)    edges = np.quantile(expected, q)    edges[0], edges[-1] = -np.inf, np.inf   # cover the tails    exp_c, _ = np.histogram(expected, bins=edges)    act_c, _ = np.histogram(actual,   bins=edges)    exp_p = exp_c / len(expected)    act_p = act_c / len(actual)    eps = 1e-4                              # avoid log/division by 0    exp_p = np.clip(exp_p, eps, None)    act_p = np.clip(act_p, eps, None)    return float(((act_p - exp_p) * np.log(act_p / exp_p)).sum())# scores = default probability (class 1)tr_log  = m_log.predict_proba(X_train)[:, 1]te_log  = m_log.predict_proba(X_test)[:, 1]tr_bst  = m_boost.predict_proba(X_train)[:, 1]te_bst  = m_boost.predict_proba(X_test)[:, 1]psi_log  = population_stability_index(tr_log, te_log)psi_bst  = population_stability_index(tr_bst, te_bst)print(f'PSI logistic regression: {psi_log:.4f}')print(f'PSI gradient boosting:  {psi_bst:.4f}')

Pentru un split train/test dintr-un set curat, valorile așteptate sunt mici (sub 0,10), pentru că antrenarea și testul provin din aceeași populație. Acest rezultat e așteptat și tot merită raportat: stableește comportamentul de bază al indicatorului și arată că modelele sunt stablee intern. Se poate raporta și PSI pe fiecare bin, pentru a arăta unde se concentrează driftul.
6.7 Proof of mechanism vs. real application
On the Taiwan data, PSI (train-vs-test) is a proof of mechanism: it shows the indicator works and integrates with the SAFE analysis, but it is NOT calendar-time drift. Real monitoring over periods requires longitudinal data (multiple periods). The Lendox dataset — which contains observation_date and outcome_date — is the one that enables PSI as real-time governance monitoring. State this explicitly in the paper.
