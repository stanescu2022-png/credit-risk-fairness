## Locked empirical protocol
- UCI Default of Credit Card Clients (Taiwan): 30,000 records; default=1 denotes next-month default.
- Repaired fixed partition: 24,004 train / 5,996 holdout; 1,320 holdout defaults.
- Retain every record, including exact input matches with different outcomes or SEX.
- Original target-stratified 80/20 split, seed 42, repaired by assigning each exact 22-predictor group to its lowest-ID member's original partition. Only 34 assignments changed; zero exact predictor groups cross the partition.
- Exact predictor equality is a conservative grouping convention, not proof of the same client.
- ID, SEX and target are excluded from predictors. SEX=1 male / 2 female remains audit metadata. Exclusion alone does not establish fairness.
- Clean EDUCATION 0/5/6 to 4; MARRIAGE 0 to 3.
- 22 predictors: LIMIT_BAL, AGE, BILL_AMT1-6, PAY_AMT1-6, EDUCATION, MARRIAGE, PAY_0, PAY_2-6. Use the saved pipeline's actual feature_names_in_ order; the grouped FEATURES constant order is not a substitute for it.
- Numerical preprocessing uses StandardScaler; categorical predictors use OneHotEncoder. Both fitted preprocessing/classifier pipelines are frozen.
- LR: max_iter=2000, random_state=42. GBM: existing sklearn defaults, random_state=42.
- Default probabilities correspond to class 1; reference classification is strictly p(default)>0.50, with equality assigned class 0.
- Average Precision (AP) means sklearn average_precision_score, not trapezoidal PR-AUC. Historical archived labels are retained.
- Holdout had already been inspected before the lock; it cannot be called historically unseen.
- No holdout-driven fitting, tuning, recalibration, threshold selection, feature changes or resplitting.
- Training-only five-fold StratifiedGroupKFold, shuffle=True, seed 42, with complete preprocessing fitted separately per fold.
- Sampling intervals: 2,000 whole exact-predictor-group resamples, seed 42, 95% percentile intervals, shared draws between models. Groups can cross SEX/outcome; do not force strata by splitting groups.
- Fairness signed gaps: female minus male. Positive predictions are adverse default-risk flags, not credit approvals.
- Threshold candidates and the exploratory fairness holdout threshold sweep are descriptive; neither selected a replacement operating threshold.

## Robustness protocol and results
Authentic SAFE 0.8.3 exchanges opposite evaluation-input tails; p is a tail fraction, not a percentage change in feature values. Its evaluation-defined tails are an explicit exception to training-only parameter estimation. RGR compares original probability magnitudes against perturbed ordering with model-specific normalization; it is not simply Spearman correlation.

SAFE grid: p=.01/.025/.05/.10; 22 individual features and eight groups at every level (120 scenarios), plus one all-feature p=.05 row-order diagnostic, seed 20261008. Nominal participation per individual feature: 118/298/598/1,198 rows; actual changes can be fewer because of ties. Joint union exposure can be much greater. Preserve canonical order as primary.

Semantic layer: each feature and all features jointly at q=.10/.20 (46 stochastic scenarios), 30 repetitions each, master seed 20261007 with deterministic child seeds and coupled/nested masks and signs. Money changes by signed .10/.20 training IQR; age by ±1/±2; positive ordinary repayment codes by exact supported ±1/±2 months; special -2/-1/0 states stay unchanged; nominal categories change using training frequencies conditional on differing. Training-support bounds, integer rounding, clipping and no-op cases are documented. The joint layer concentrates changes in a common selected-record mask. Layers are not severity-equivalent.

Total: 167 scenarios / 1,501 realizations.

| Primary joint scenario | Model | RGR | Flip rate | AP change |
| --- | --- | ---: | ---: | ---: |
| SAFE p=.05 | LR | 0.8170 | 11.44% | -0.1806 |
| SAFE p=.05 | GBM | 0.8272 | 11.12% | -0.1924 |
| Semantic q=.10 | LR | not authentic SAFE RGR | 0.79% | -0.0055 |
| Semantic q=.10 | GBM | not authentic SAFE RGR | 1.30% | -0.0131 |

SAFE joint input exposure is 65.1% versus approximately 10% semantic exposure. Semantic all-record mean absolute probability movement: LR .00509, GBM .00827; GBM-minus-LR .00318, conditional 95% CI [.00297,.00340]. Repetition SDs .00040/.00054 are Monte Carlo variability, distinct from sampling uncertainty. SAFE paired intervals are mostly inconclusive; read sampling_intervals.csv metric by metric.

Bootstrap conditions on frozen models and the saved SAFE realization or 30 saved semantic realizations. It does not repeat data-dependent tail formation on new samples. Nonlinear metrics are calculated per repetition, then averaged; never average probabilities first or count repetitions as additional clients. Metric deltas are perturbed minus baseline; paired differences GBM minus LR. RGR has point estimates only.

Row order affects tied tail membership: 1,225 records differ in exposure membership after permutation. Canonical results remain primary. Group robustness comparisons distinguish exposure from model response; they do not establish discrimination. The experiments do not establish real-world error frequencies, causal behavioral effects, adversarial security, future population reliability, or framework novelty.
